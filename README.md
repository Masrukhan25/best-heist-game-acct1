A complete, original heist game for the make.fun bounty "Make the best heist game". Thief Vane, the Fox of Carrowmere, steals through five wings of the Ashworth Museum: 5 heists, 18 guards, 33 treasures, 4 gadgets. Top-down stealth with raycast vision cones, light and shadow, cameras, lasers and a three-level alarm. Plays offline in a desktop browser from game/index.html.
